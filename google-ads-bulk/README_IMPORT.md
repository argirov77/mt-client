# Импорт ad groups в Google Ads (Maximov Tours, 639-694-9407)

Пакет для bulk-загрузки через **Google Ads Editor** (API недоступен — developer token не одобрен).
Создаёт **7 ad groups** (RU, exact match) в уже существующей Search-кампании.
Группа «Одесса — Варна» и все UA-группы, «Золотые пески» — в этот пакет **не входят**.

## ⚠️ Проверьте ДВА пункта перед импортом

### 1. Имя кампании
Во всех трёх CSV в колонке `Campaign` стоит:

```
Search — Маршруты — Exact — UA/BG
```

Google Ads Editor сопоставляет кампанию по **точному** совпадению имени. Если в
аккаунте кампания отображается как `Sales-Search-1` (или иначе) — откройте все три
CSV и сделайте find-and-replace имени кампании на реальное **до** импорта, иначе
Editor создаст новую кампанию вместо добавления групп в существующую.
Тире в имени — длинное (`—`, U+2014), с пробелами вокруг; скопируйте имя из аккаунта целиком.

### 2. Проверка Final URL на 200
Прямой HTTP-запрос из среды генерации был заблокирован сетевой политицей
(403 на CONNECT к `maximovtours.com`), поэтому автоматический 200-check **не выполнялся**.
Вместо него все 7 Final URL сверены с боевым `sitemap.xml` сайта — **все 7 присутствуют**
в карте сайта (RU-слаги, priority 0.7–0.9). Тем не менее перед `Post changes` откройте
каждый URL в браузере и убедитесь, что отдаётся 200, а не 404:

- https://maximovtours.com/odessa-burgas
- https://maximovtours.com/varna-odessa
- https://maximovtours.com/odessa-solnechniy-bereg
- https://maximovtours.com/burgas-odessa
- https://maximovtours.com/solnechniy-bereg-odessa
- https://maximovtours.com/odessa-constanta
- https://maximovtours.com/constanta-odessa

Если какой-то URL отдаёт 404 — **не импортируйте** соответствующую группу, сообщите,
какой URL сломан. Подставлять другой URL самостоятельно нельзя.

## Файлы в пакете

| Файл | Что создаёт | Колонки |
|------|-------------|---------|
| `adgroups.csv` | 7 ad groups, все `Paused` | Campaign, Ad Group, Status |
| `keywords.csv` | 35 ключей (5 на группу), Exact, Enabled | Campaign, Ad Group, Keyword, Criterion Type, Status |
| `ads.csv` | 7 RSA (12 заголовков + 4 описания на группу) | Campaign, Ad Group, Ad type, Headline 1..12, Description 1..4, Final URL, Path 1, Path 2, Status |

- Кодировка: **UTF-8 с BOM**, разделитель — запятая.
- Ключи в CSV — **без квадратных скобок**; тип совпадения задаётся колонкой `Criterion Type = Exact`.
- Группы создаются `Paused` (включите вручную после проверки). Объявления `Enabled` —
  этого достаточно, пока группа на паузе показов не будет.

## Пошаговый импорт

1. Скачайте и установите **Google Ads Editor**
   (https://ads.google.com/home/tools/ads-editor/), залогиньтесь под аккаунтом
   Maximov Tours (639-694-9407) и выполните **Get recent changes** для этого аккаунта —
   чтобы в Editor подтянулась существующая кампания и группа «Одесса — Варна».
2. **Account → Import → From file** и импортируйте по очереди, именно в этом порядке:
   1. `adgroups.csv`
   2. `keywords.csv`
   3. `ads.csv`
   (Порядок важен: ключи и объявления привязываются к группам, которые создаёт первый файл.)
3. Просмотрите **pending changes**. Проверьте предупреждения Editor — особенно по длинам
   строк (лимиты: заголовок ≤30, описание ≤90, ключ ≤80 символов и ≤10 слов). Все строки
   в пакете уже посчитаны и укладываются в лимиты (см. «Проверка длин» ниже), но Editor —
   финальный арбитр.
4. **Post changes**.
5. Откройте веб-UI Google Ads и убедитесь, что все 7 групп появились в нужной кампании,
   ключи и RSA на местах. Затем **включите группы** (они импортируются `Paused`).

## Заметки по содержанию (соответствие ТЗ)

- Год основания везде **1992** (не 1991).
- Ключи — только русские написания (одесса, билеты, солнечный берег). Украинские
  формы (одеса, квитки, сонячний берег) **не включены**.
- Для «Солнечный берег» пара `... билеты` уложилась в 30 символов (29), поэтому оставлена.
- Никаких ключей/заголовков сверх ТЗ «для полноты» не добавлено.
- Регенерация: `python3 gen.py <output_dir>` (скрипт валидирует все лимиты и падает при нарушении).
